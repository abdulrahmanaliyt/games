# Ludo Dice Game 🎲

A simple Ludo Dice Game built using HTML, CSS, and JavaScript. Roll the dice and enjoy a fun, interactive gaming experience directly in your browser.

## Features
- Interactive dice rolling
- Random dice outcomes from 1 to 6
- Animated dice result
- Simple and user-friendly interface
- Responsive design

## How to Play
1. Open the game in your browser.
2. Click the **Roll Dice** button.
3. Watch the dice roll and display a random number.
4. Roll again and enjoy!

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Live Demo
[Play Ludo Dice Game](https://abdulrahmanaliyt.github.io/games/Ludo-game/index.html)

## Run Locally
1. Clone or download this repository.
2. Open the `Ludo-game` folder.
3. Open `index.html` in your browser.
