# Simon Game 🎮

A simple and interactive Simon Game built using HTML, CSS, and JavaScript. Test your memory by repeating the sequence of colors in the correct order.

## Features
- Interactive color buttons
- Increasing difficulty with each level
- Sound and visual feedback
- Keyboard and touch support
- Simple and responsive user interface

## How to Play
1. Open the game in your browser.
2. Press any key or tap the screen to start.
3. Watch the color sequence carefully.
4. Repeat the sequence by clicking or tapping the colored buttons.
5. Each level adds another step to the sequence.
6. If you make a mistake, the game ends. Try again and beat your highest level!

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Download or clone this repository.
2. Open the `Simon` folder.
3. Open `index.html` in your browser.
